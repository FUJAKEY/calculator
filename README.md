# Advanced Calculator

Приложение представляет собой полноценный научный калькулятор для Android (ARM64), включающий:

- базовые арифметические операции;
- расширенный научный режим с тригонометрическими, логарифмическими и экспоненциальными функциями;
- поддержку констант `π`, `e`, факториала и работы с процентами;
- интерактивное построение графиков функций с масштабированием и панорамированием;
- историю вычислений с возможностью повторного использования выражений.

## Стек

- Kotlin + Jetpack Compose
- Material 3 дизайн-система
- Собственный движок разбора и вычисления выражений

## Сборка локально

```bash
./gradlew assembleRelease
```

При первом запуске скрипт Gradle Wrapper автоматически скачает отсутствующий `gradle-wrapper.jar` из официального репозитория Gradle.
Для загрузки требуется наличие `curl` или `wget` и доступ в интернет.

APK (arm64-v8a) будет доступен по пути `app/build/outputs/apk/release/app-release-unsigned.apk`. Для локальной установки можно
использовать debug-сборку `app/build/outputs/apk/debug/app-debug.apk`.

## Запуск проверок

```bash
./gradlew lint test
```

## Структура проекта

- `app/src/main/java/com/example/advancedcalculator` — исходный код (UI и бизнес-логика).
- `app/src/main/res` — ресурсы приложения.
- `.github/workflows` — CI/CD для автоматической сборки APK.

Минимально поддерживаемая версия Android — 8.0 (API 26).

## GitHub Actions

В репозитории присутствует workflow, который собирает релизный APK и публикует его в артефактах каждой сборки.
